Private Local Chat model CDN: operations

CURRENT (since 2026-11-17, T587/T674/T677)

The app's models come from the programme's shared data CDN, https://cdn.aiofourown.com (R2 bucket cosmoshot-cdn), which infra runs. It holds data
only (no .wasm). Publish with /cosmoshot/tools/ops/cdn_publish.py (publish, verify, status, rollback, set-current, catalog; read the section "Shared CDN
publish, verify, roll back" in /cosmoshot/tools/ops/README.md) and check every published version with /cosmoshot/infra/cloudflare/cdn_verify.py.
Header rules, retention and backup: /cosmoshot/infra/docs/CDN-DESIGN.md. Catalogue: https://cdn.aiofourown.com/catalog.json.

What stays in this folder is PLC's own data, the record of what the app asks for:
  model-cdn-manifest.json      every pinned data file of the nine families (key, size, SHA-256, URL on the shared CDN)
  pinned-model-catalog.json    the upstream revisions and hashes the app catalogue was generated from
  gguf-models.json, voice-models.json, memory-models.json   the pins of the wllama models, the voices and the search model
  licenses/                    the licence texts published beside each model
  cdn-inventory.json, model-object-verification.json          older records, not maintained

RETIRED BUCKET (record only, not maintained)

Until 2026-11-17 the files were served from the project's own R2 bucket privatelocalchat-assets at https://assets.privatelocal.chat (account and
zone ids in cdn-state.json; its last public check is public-cdn-verification.json, 2026-11-02). That host now redirects /models/* to the shared CDN
(applied 2026-11-17 22:10 EST by infra on PLC's written word on T674); *.wasm and /models/catalog.json stay on it. Infra removes the old objects only on
PLC's written word on T677, after a hash-verified copy (retirement runbook: /cosmoshot/infra/docs/RETIREMENT-RUNBOOK-PLC.md).

The scripts that provisioned, filled and checked that bucket (provision-cdn.py, publish-models.py, publish-gguf.py, publish-files.py,
publish-embedding.py, update-catalog-index.py, verify-cdn.py, migrate-hosting.py) were deleted in T677 because the shared tool does the same job; they are
in git history (see commit "refactor(ops): delete the old publishers, keep only PLC's pin data" and its parent).

The old bucket's rules, for the record: weights (.gguf, .bin) carried Cache-Control no-store so the app's own OPFS or Cache API copy is the only
offline copy; everything else was public, max-age=31536000, immutable; CORS allowed any origin with Range; model paths carried pinned source revisions.
Apache-2.0 LICENSE files accompanied the Qwen model directories; the matching WebLLM libraries came from mlc-ai/binary-mlc-llm-libs (Apache-2.0).
